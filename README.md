# MineLot 移植版（1.20.1-forge）
本项目是经典模组 **MineLot** 的非官方移植版本，原模组作者为 Jimbopanda12。
原版模组相关网站现已失效，不再维护更新。

本模组移植了原版中的各类武器、矿石，武器机制基于 Minecraft 原版武器系统实现。
本次仅移植矿石与武器相关内容，暂不包含原版其余功能，后续暂无持续更新计划。

## 更多信息
- 相关数值并未依照原版模组
- 已移植内容：矿石、全部武器
